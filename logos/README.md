# Logos

Computed vectors, transparent, colours baked in (`<img>` does not inherit colour).

| File | Use | Colours |
|---|---|---|
| `onefold-mark.svg` | Primary mark with depth, light grounds, from 32 px | petrol gradient #17717c → #0a4a53, saffron gradient #fbd468 → #f2b630 → #d98e17, shadow |
| `onefold-mark-on-dark.svg` | Mark with depth on dark grounds | petrol gradient #3aa3ad → #1f7880, saffron, stronger shadow |
| `onefold-mark-1024.png` | Raster of the primary mark | as above |
| `onefold-mark-flat.svg` | Flat mark, 16–32 px, favicons | `petrol` #0e5a64, `saffron` #f2b630 |
| `onefold-mark-ink.svg` | One colour, dark | `ink` #111719 |
| `onefold-mark-white.svg` | One colour, light, on photos and `petrol` | #ffffff |
| `onefold-lockup.svg` | Mark + ONEFOLD LABS, horizontal, light | mark with depth, text `ink` |
| `onefold-lockup-on-dark.svg` | Horizontal, dark | text #ffffff |
| `onefold-lockup-ink.svg` | Horizontal, one colour | `ink` |
| `onefold-lockup-stacked.svg` | Stacked, light | `ink`, LABS in `petrol` |
| `onefold-lockup-stacked-on-dark.svg` | Stacked, dark | white, LABS in `saffron` |
| `onefold-avatar.svg`, `onefold-avatar-1024.png` | GitHub organisation, social profiles | mark with depth on `paper` |
| `onefold-lockup-1024.png` | Raster version where SVG is not accepted | text `ink` |
